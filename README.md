# Deepl Unlimited Hack
Was noch implementiert werden kann:

Nur will ich nicht, dass es mir dieses TXT File automatisch  herunterlädt. Ich möchte, dass sobald es alles zusammengetragen hat, einen Text sehe dass der Text fertig konvertiert worden ist und ich dann einen Button sehe wo draufsteht wie ich es, also in welchem Format ich den Text herunterladen möchte. 

Entweder in TXT, in Word oder als PDF. Zudem möchte ich, dass der zu konvertierte Text und der konvertierte Text beide gespeichert werden für den Verlauf. Ich will eine Seite haben auf der ich auf den Verlauf komme und ich sehe, in welchem Datum es konvertiert wurde und kann es jederzeit wieder durch die Verschiedenen Möglichkeiten easy herunterladen. Zudem soll es auch die Möglichkeit geben, die beiden Textversionen also den jeweiligen Verlaufeintrag zu löschen. Zudem wäre noch eine Einsicht über die Textuellen unterschiede unheimlich hilfreich.

Eine Funktionalität die ich mir zudem noch wünschen würde ist  die, dass man eine Schleife definieren kann mit mehreren Texten. Zum Beispiel erstelle ich eine Schleife, und füge einen Text der 2000 Zeichen gross ist, der andere 8000 und der dritte vielleicht 5000. Darüber hinaus wenn ich die Schleife starte für dessen konvertierung auf Deepl, soll es mir dann jeden einzelnen Text separat sauber konvertieren, sodass es mir sehr viel flexibilität bietet. Zudem soll dies ebenfalls in einem separaten Verlauf mir angezeigt werden. Ich möchte, dass du dabei die nötigen Pages sehr schön und durchdacht für mich erstellst sodass es für den Benutzer möglichst einfach, simple und durchdacht wirkt mit maximalster professionalität. Bitte schreibe das CSS in Bootstrap für weniger Code.
