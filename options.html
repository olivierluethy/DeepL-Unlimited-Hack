About usage data

To understand which features matter and which don't, this extension sends anonymous usage data to PostHog on EU servers (eu.i.posthog.com). The data is tied to a random ID generated on this device — it cannot be linked to your name, email, or DeepL account.

What is collected

  • Which buttons / tabs you use
  • Character-count buckets (e.g. "2k–5k")
  • Translation success / failure type
  • Extension version, browser interface language
  • The random anonymous ID below

What is never collected

  • The text you translate, paste, or copy
  • Your IP address (dropped server-side)
  • Browsing history
  • Email, name, or account data
  • PDF / Word contents

Your anonymous ID

Provide this ID if you want your data deleted (GDPR / Swiss FADP Article 17, right to erasure).
