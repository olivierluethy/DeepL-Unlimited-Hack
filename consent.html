Help improve DeepL Pro Unlimited

We'd like to understand which features are useful so we can keep what matters and retire what doesn't. Sharing anonymous usage data is optional.

What we collect

  • Which buttons and tabs you use (e.g. Magic Fix, Documents)
  • Character-count buckets (e.g. "2k–5k") — never the text itself
  • Translation success / failure and the type of error
  • Extension version and your browser's interface language
  • A random anonymous ID generated on this device

What we never collect

  • The text you translate, paste, upload, or copy
  • Your IP address (PostHog drops it server-side)
  • Browsing history or pages you visit
  • Email, name, or any account data
  • File contents of PDFs, Word, Excel, or PowerPoint files

Data is sent to PostHog on EU servers (eu.i.posthog.com). You can change your mind at any time from the extension's Settings page.
